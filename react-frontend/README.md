# CoursePath frontend

The React interface for **CoursePath — Student Course Planner**.

See the [project README](../README.md) for setup, features, storage behavior, the optional MongoDB backend, and project limitations.

```bash
npm ci
npm run dev
npm run build
npm run lint
npm test
```

Requires Node.js 22.12 or newer. The current frontend saves data in browser localStorage and does not require MongoDB.
